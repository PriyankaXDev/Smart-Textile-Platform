# Smart Textile Manufacturing Platform

## Project Description

The Smart Textile Manufacturing Platform is a software system designed to support textile manufacturing operations through digital monitoring and management. The project demonstrates the development, containerization, testing, and version control of a software application.

## Features

- Health check API for monitoring application availability
- REST API developed using FastAPI
- Docker containerization
- Docker Compose configuration
- API documentation using Swagger UI
- Git-based version control
- Feature and development branch workflow

## Technology Stack

- Python 3.11
- FastAPI
- Uvicorn
- Docker
- Docker Compose
- Git and GitHub
